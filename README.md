# PakMobile POS (پاک موبائل پی او ایس)
### Production Mobile Accessories Shop Management App for Pakistan
**Cloud Backend: Firebase Firestore + Authentication**

Designed specifically for Pakistani mobile accessories shops selling cases, tempered glass, fast chargers, cables, earbuds, and accessories across **Retail** and **Wholesale** tiers with first-class **Udhaar (Credit)** tracking and Firebase Firestore backend.

---

## 🌟 What's New & Updated

1. **Clean Start (Zero Dummy/Demo Entries)**:
   - All dummy products, invoices, and mock customers removed. The shop starts completely clean so you can enter your real inventory immediately.
   - A single-click "Wipe All Data Clean" button in Settings if you ever want to reset.

2. **Delete Option Everywhere**:
   - **Delete Products & Variants**: Red trash icon on every product row with instant permanent removal.
   - **Delete Invoices**: Delete any invoice permanently from the Invoices screen.
   - **Delete Customers**: Delete any customer account from the Customers screen.
   - **Delete Stock Movements**: Delete or audit any movement record.
   - **Delete from Cart**: One-click removal of any item from current POS sale.

3. **No Forced Details (Zero Form Friction)**:
   - **Add Product**: Only **Name** and **Retail Price** are required! All other fields (Urdu name, model, color, brand, SKU, purchase unit, cost) are completely optional.
   - **Add Customer**: Only **Name** is required! Phone number and address are completely optional.

4. **Custom Item / On-the-Fly Entry (`+ Custom Item`)**:
   - Easily enter any custom accessory name, price, and quantity directly in the POS screen without having to create a product in the catalog first!
   - Ideal for random items, repairs, used accessories, or unique customer requests.
   - Optional checkbox to save the custom item to the product catalog if desired.

5. **Removed Recommended Mobiles Presets**:
   - Removed cluttered hardcoded phone model chips. You have total freedom to type any phone model or accessory name you sell.

6. **Firebase Firestore Cloud Backend**:
   - Fully provisioned Firebase Firestore database (`resounding-sublime-7bvhw`).
   - Real-time cloud sync with automatic offline local caching so the app works instantaneously even on slow connections.
   - Tested and secured with Firestore security rules (`firestore.rules`).
